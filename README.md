# Net Annual Premium Calculator

## Project Overview

An Excel-based insurance premium calculator developed to calculate net annual premiums for different traditional insurance and annuity products.

The project demonstrates the application of actuarial concepts, Excel formulas, and spreadsheet modelling to automate premium calculations.

## Products Covered

The calculator includes six traditional insurance and annuity products:

- Whole Life Insurance
- Endowment Insurance
- Term Insurance
- Pure Endowment
- Deferred Annuity
- Immediate Annuity

## Tools Used

- Microsoft Excel
- Excel formulas
- Actuarial calculations
- Spreadsheet modelling

## Key Features

- Calculates net annual premiums based on user inputs
- Supports multiple insurance and annuity products
- Uses actuarial present value calculations
- Provides a structured and user-friendly calculation interface
- Automates repetitive premium calculations

## Project Structure

`Net_Annual_Premium_Calculator.xlsx`

Contains the complete Excel calculator, including input sections, calculations, and outputs.

## Purpose

This project was developed to demonstrate practical application of actuarial science, financial modelling, and Excel-based analytical skills.
